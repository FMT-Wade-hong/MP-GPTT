# FeiMaoTecPlanner V1.1.6

- 新增 P400 DATA/AT 設定、PicoConfig 備用視窗、手冊功能說明與預設值。
- S107 可遮蔽輸入新密碼；S102/S110 須用 CONFIG 強制 9600/8N1 AT 模式設定，返回 DATA 後使用新值。
- 新增主／副頻率表讀写、50 筆編輯、CSV 匯入匯出、貼上及 10 個自訂組合；寫入前備份，完成後讀回比對。
- 修正 SiK 頻率讀回、功率選項與設定頁名稱，加入 H420 基礎參數及 Throttle Accel 輸入調整。
- 更新五個工具列圖示、工具列高度、電池顯示及導控切換介面，移除 QNH 入口。

## 使用方式與限制

下載 `FMTPlanner-V1.1.6.zip`，完整解壓後執行 `FMTPlanner-V1.1.6.exe`，不要只複製 EXE。

本版完成編譯及模擬通訊測試，尚未完成實機端到端驗證。數傳設定可能造成失聯；頻率寫入僅支援 S128=2/S238=1，需完整 50 筆，配對端不會自動同步。密碼遮蔽回覆無法驗證原文。請在拆槳或無動力的地面安全狀態驗證後再使用。

發布內容僅含 Windows 程式及公開文件，不含個人設定、通訊記錄、頻率組合備份或私密簽章。
