# H420 基礎參數

來源：使用者提供的 `2026-09-09 16-03-12.bin`，ArduCopter V4.6.3 (3fc7011a)，SDMODELH7V1，QUAD/X。

- `H420-source-full.param`：紀錄中 1,204 個參數的最後記錄值，供追溯，不放入機型選單。
- `H420.param`：183 項構型、馬達、控制、導航及濾波設定，內嵌於程式，可離線載入。

紀錄期間有調參，因此採用每個參數最後一次出現的值。基礎檔未包含單機感測器校正、RC 端點、裝置識別、電池與失效保護策略、通訊埠、累計運行數據。這些項目須依實際設備配置。

保留來源的四旋翼 X 構型及特殊馬達輸出順序：SERVO1–4_FUNCTION 為 36、33、34、35。套用對象須具備相同配置。此檔是提供紀錄的設定基準，並非另一台 H420 的飛行驗證結果。

在參數機型選單選取 H420.param 後，沿用既有參數比較流程；載入不會自動寫入飛控。
