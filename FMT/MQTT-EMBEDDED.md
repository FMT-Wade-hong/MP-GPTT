# 地圖內嵌 MQTT 連線

在飛行資料頁的地圖下方勾選「MQTT 連線」。面板與「3D 地圖」、調校曲線共用主地圖上方的區域，一次顯示一種。底部座標與選項列固定為單列高度，寬度不足時水平捲動，不再換行增高或壓縮地圖。MQTT 設定面板本身仍可捲動。

## 使用

1. 可從原本的 Windows MQTT 橋接器匯出 `.fmt`，在新面板匯入。檔案不包含密碼，匯入後須重新輸入。
2. 確認 Broker 主機、MQTT Port、TLS、Client ID、帳密、上下行 Topic。Client ID 不可與另一個同時連線的裝置重複。
3. 同一台電腦使用時，TCP 監聽 IP 可填 `127.0.0.1`，TCP Port 可填 `8080`。若舊橋接器仍占用該埠，先停止舊橋接器或使用另一個未占用埠。
4. 按「啟動橋接」，確認顯示「MQTT 已連線／已訂閱」。
5. 在 MP 上方連線選單選 TCP，輸入面板提示的 IP 與 Port。MQTT 連線成功、MP TCP 連線成功、收到飛控 MAVLink 心跳是不同階段。

取消勾選、切回 3D 地圖或曲線只會隱藏面板，不停止橋接。按「停止橋接」或結束程式才釋放連線。MQTT 斷線會自動重連；斷線期間的 MP 資料不暫存、不補送。訂閱拒絕不會顯示已連線；retained 歷史資料不會送入 MP。

## 上方 MQTT 即時速度

啟動橋接後，飛行時間左側顯示使用者提供的 MQTT 圖示，以及上下兩列「接收」「傳送」速度。每 0.5 秒依實際經過時間取樣，單位為 B/s、KiB/s 或 MiB/s（位元組／秒），不是累計流量。第一筆取樣與重新啟動時由 0 B/s 開始；沒有資料流動時顯示 0 B/s。

直升機模式排列為「轉速計 → MQTT → 飛行時間」，各區塊緊鄰且不疊放。停止橋接後 MQTT 區塊隱藏並收回空間。收合 MQTT 設定面板、切換分頁或 MP 尚未連線，都不影響橋接執行時的速度更新；Broker 重試期間仍顯示，數值不代表飛控連線或 MAVLink 已就緒。

以上功能已整合至 V1.1.3，使用發布包內的 `FMTPlanner-V1.1.3.exe`，需保留同資料夾相依檔案。

## 防止誤關閉

MP 任一遙測連線開啟，或 MQTT 橋接仍在執行（包含收合與重連中）時，按主視窗 X、Alt+F4 或正常結束程式會跳出確認提示。預設選擇「否」；按「否」或 Esc 會保持程式與連線，只有明確選「是」才執行關閉清理。全部斷線且橋接已停止時不提示。Windows 關機不彈出此提示；工作管理員強制結束或斷電也無法靠此功能阻止。

V1.1.3 已包含此保護；仍請先停止任務並安全斷線，再結束程式。

## 儲存與安全

- 設定存於 `%LOCALAPPDATA%\FMTPlanner\Mqtt\settings.json`，不包含密碼。
- 勾選「安全記住密碼」時，另外以 Windows DPAPI CurrentUser 保護密碼，並綁定 Broker 主機、埠與帳號。不勾選並啟動時會移除本功能先前儲存的密碼。
- TLS 使用 Windows 憑證信任與主機名稱驗證，不忽略憑證錯誤。不需要在此填入 Broker 私鑰。
- 此功能未變更 VM、Broker ACL 或飛機端 DTU 設定，也未自動連線到正式 Broker。
- 一個面板提供一對一、MQTT 3.1.1 / QoS 0 的二進位 TCP 橋接。先在地面、無槳且安全狀態下驗證遙測和斷線行為，再評估實際使用。

## 驗證與測試版

執行 `powershell -ExecutionPolicy Bypass -File FMT\Verify-FmtMqtt.ps1` 可編譯並執行本機回歸測試，輸出位於 `tmp\mqtt-tests`。測試僅使用 loopback 模擬 Broker 與合成帳密，包含 `.fmt`、UI 捲動與密碼遮罩、隱藏面板仍保持連線、雙向二進位資料、拒絕訂閱、重連及停止釋放連接埠。

主程式編譯與本機測試不等於正式 Broker TLS、DTU 或實機飛控端到端驗證；這些仍須在現場確認。新版不會自動帶入使用者的 Broker 帳密或取代既有的飛機端設定。
