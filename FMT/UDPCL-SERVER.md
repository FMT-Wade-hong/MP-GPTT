# UDPCl Server 主站轉發（測試版）

1. 主站先連接飛控，設定為 1 號站，開啟「MAVLink 轉發」。
2. 按「新增主站 UDPCl Server」，會新增 UDP / Inbound / 14550 的設定列；按該列「啟動」。連接埠可在啟動前修改。
3. 頁面列出啟用中網路介面的 IPv4。選擇分站可到達的網卡 IP；不要將 0.0.0.0 當成分站的連線目標。網路改變後按「更新主站 IP」。
4. 分站在主連線選 UDPCl，輸入主站 IP 與相同連接埠，按連線；不需在分站另建相同轉發列。主站防火牆需允許該 UDP 埠。
5. 多個分站可共用主站同一個埠。主站收到分站封包後回傳遙測；30 秒沒有封包的端點會移除，重新收到封包後可再次加入。主站需持續收到飛控資料，才會處理轉發。

## 控制回寫

預設「允許回寫」關閉。啟用後，每個 UDP 封包都依來源 IP 查詢接力站台身分與目前控制權，不使用整列固定站號來授權全部用戶。需先完成接力站台設定／上線，只有唯一對應到站號、且通過既有接力授權的分站可以回寫。共用 IP／NAT 導致身分不明時拒絕回寫。

IP 對應並不是密碼驗證或加密；僅在可信任的區域網路或 VPN 使用，不要直接暴露到公共網路。未修改系統防火牆，未自動連接飛控，未自動開啟回寫。

## 驗證

`FMT/Test-UdpRelayServer.ps1` 使用本機 loopback UDP 與模擬飛控接收端，檢查多用戶回傳、逐包授權、唯讀模式及逾時清理。仍需在實際 1～5 號站、未解鎖／安全地面狀態驗證。
