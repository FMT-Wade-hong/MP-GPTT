# FeiMaoTecPlanner V1.2.0

正式發布版，非 RC／預覽版。

## 更新內容

- 復原電源模組 1／2 設定入口，保留必要的連線與參數讀取條件。
- 頁籤選單中文化，保留原有設定；地圖網格、KML、自訂地圖及載入狀態使用繁體中文。
- 校正起降、RTL、精準降落、電池 failsafe、解鎖檢查與電源模組換算說明，保留參數名稱、專有名詞、原始選項與 bit 索引。
- 延續精確版本 metadata 匹配與既有 ELRS、LOG 下載、參數比對、接力控制與圖示修正。

## 下載與使用

下載 `FMTPlanner-V1.2.0.zip`，完整解壓縮後執行 `FMTPlanner-V1.2.0.exe`，勿只複製 EXE 或直接從 ZIP 內啟動。升級前請備份設定；附 SHA-256 校驗檔。

## 驗證與限制

- 編譯 0 錯誤、1,390 個警告；13 組離線回歸通過，包含 156 個翻譯語意案例。
- 58 份公開 metadata 的 3,934 種說明有中文；3,335 種選項保留原始值與 bit 索引。中文覆蓋不代表全表逐條語意複核已完成。
- Copter 4.5.7／4.6.3／4.7.1 指定導航／控制參數的精確版本測試通過，不代表所有機型、所有 patch 版本均已驗證。
- 未完成實機飛行或 5–10 台群飛驗證；請先完成地面驗證再用於正式飛行。
- 發布包排除私人參數、憑證、使用者設定、日誌及測試產物。
