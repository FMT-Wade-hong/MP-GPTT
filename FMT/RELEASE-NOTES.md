# FeiMaoTecPlanner V1.2.6

新增舵角指示器與任務重置，補齊 4.7.3 參數說明，改善首次參數讀取、任務清除及長時間操作穩定性。

## 主要更新

- **舵角指示器**：主頁下方「安全設定」右側開啟浮動儀表，顯示副翼、FLAP、升降舵及方向舵；PWM TRIM 為中立點，由使用者輸入端點角度。數值為 PWM 換算估計，並非實際舵面角度回授。
- **參數資料與下載**：補入五種機型的 4.7.3 資料，共 36 組內嵌版本；自動下載精確版本並快取。後續版本同名參數可參考較舊說明並標示來源，不沿用未確認的單位／選項。首次參數下載核對總數、索引與唯一名稱，缺漏補讀，完整才保存。
- **任務重置與清除**：「跳轉航點」旁新增重置；「Write Fast」改為清除飛控任務，成功後讀回確認數量為 0，保留 HOME、電子圍籬與集結點。重置允許解鎖／飛行中確認操作，AUTO 中可能立即重新執行開頭指令；不會自動解鎖或切換模式。
- **介面與校正**：飛行記錄工具中文化、未讀取任務文字、移除地圖大範圍避障圈；空速計歸零使用相容的氣壓計／空速計校正命令。
- **穩定性**：設定檔原子替換與競爭處理、3D 失效返回 2D／重新開啟、FTP 視窗關閉與取消清理。
- **GitHub 問題修復**：OSD 名稱及回覆時序、ADS-B 高度／升降率／威脅色、動作參數與 INT 任務請求、DroneCAN 清單完整性、簽署金鑰原檔保護、外掛快取、電池小數及重複目錄等。

## 相容性與驗證

內建 HTTP 56781 改為僅 IPv4 loopback，raw WebSocket 只提供遙測讀取。其他電腦直接存取此埠的舊流程不再適用；專用 MQTT／UDP 轉發維持原流程。

Release 建置 0 errors（1,378 warnings）；92 組離線功能回歸全部通過。10 分鐘正常垃圾回收連續測試完成 GDI／OpenGL 各 8,483 幀、85 次 ICE 頁面生命週期；額外並行及單獨圖形測試各涵蓋 30 個控制項、300 次縮放／顯示切換與 5 次失效恢復。

先前曾觀察到的 OpenGL Error 170 本次未復現，不能據此認定根因已修復。尚未實機／實飛驗證；部分 ELRS／SiK 電壓更新及長日誌下載回報仍未重現，仍有 6 段新版參數說明保留英文。
