# FeiMaoTecPlanner V1.1.3

## 本版更新

- 新增地圖內嵌 MQTT 橋接、TLS 與 `.fmt` 設定匯入／匯出；收合面板不停止連線。
- 工具列新增透明 MQTT 圖示與接收／傳送速度，與直升機轉速計、飛行時間不重疊。
- 連線中誤關主視窗會先提示，預設保留連線。
- 初始設置 RTK 下方新增中文 SiK 數傳設定，保留獨立序列埠與寫入安全確認。
- 修正動作分頁、SiK 中文欄位與地圖底部選單的遮字／高度問題；保留底層飛控指令值。
- MQTT 密碼以 Windows DPAPI 安全保存，不包含在匯出的 `.fmt` 或發布包內。

## 下載與使用

1. 下載 `FMTPlanner-V1.1.3.zip`，完整解壓縮。
2. 執行資料夾內的 `FMTPlanner-V1.1.3.exe`；不要只複製 EXE 或在壓縮檔內執行。
3. `FMTPlanner-V1.1.3.zip.sha256` 提供下載校驗值。操作說明見包內 `README-FMT.md` 及 `FMT` 下的 MQTT／SiK 文件。

## 驗證範圍

73 項 MQTT、44 項 SiK、287 項動作分頁離線／loopback 檢查，包含 100%／150%／200% 字型與幾何縮放；另有版本與封裝檢查。不使用正式帳密、不寫入數傳或操作飛控。正式 Broker TLS、DTU、實體數傳讀寫與端到端飛行功能仍須在地面安全狀態下驗證。

本次只發布 Windows MP，不包含手機 App、VM 網頁管理工具、個人連線設定或私密簽章檔案。
