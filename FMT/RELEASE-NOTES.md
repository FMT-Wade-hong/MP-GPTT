# FeiMaoTecPlanner V1.1.4

## 本版更新

- MQTT 連線資料改為明確勾選「安全記住密碼」後才保存；未選擇時不載入舊版殘留 Broker 設定。
- 地圖下方新增獨立「安全設定」入口，以繁體中文卡片設定遙控器、地面站、電池及 EKF 失效保護。
- 遙控器校正頁新增中立回中／手動油門選項，檢查 `PILOT_THR_BHV`、RC 油門範圍與 `THR_DZ`。
- 加速度計改為六面飛機姿態提示：綠色代表完成、黃色代表目前需擺放、灰色代表尚未校正。
- 加速度計及羅盤校正頁縮為內容所需尺寸並固定靠左上；修正校正訊息遮住姿態圖卡。
- 保留 V1.1.3 的 MQTT、SiK、3D 地圖、任務列、直升機轉速與飛行安全功能。

## 下載與使用

1. 下載 `FMTPlanner-V1.1.4.zip`，完整解壓縮。
2. 執行資料夾內的 `FMTPlanner-V1.1.4.exe`；不要只複製 EXE 或在壓縮檔內執行。
3. `FMTPlanner-V1.1.4.zip.sha256` 提供下載校驗值。操作說明見包內 `README-FMT.md` 及 `FMT` 下的 MQTT／SiK 文件。

## 驗證範圍

包含 MQTT loopback、安全設定、油門模式、感測器排版、SiK、動作分頁、版本及封裝檢查。不使用正式帳密、不寫入數傳或操作飛控。正式 Broker TLS、DTU、實體數傳讀寫、感測器校正及端到端飛行功能仍須在地面安全狀態下驗證。

本次只發布 Windows MP，不包含手機 App、VM 網頁管理工具、個人連線設定或私密簽章檔案。
