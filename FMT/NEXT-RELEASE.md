# FMTPlanner 下次版本待修正清單

記錄日期：2026-08-14  
基準版本：V1.0.6  
狀態：待分析／待實作（不包含於 V1.0.6）

## 待修正項目

1. **VTOL 地圖圖示判斷**
   - VTOL／QuadPlane 連線時，地圖仍顯示固定翼圖示。
   - 預期：依目前飛控構型與 VTOL 狀態顯示專用 VTOL 圖示。

2. **縮小地圖飛行器藍色外框**
   - 現有發光藍色外框範圍過大。
   - 預期：保留辨識度與背光效果，但縮小光暈及外框尺寸。

3. **馬達測試頁面補齊固定翼／VTOL 構型資訊**
   - 馬達測試頁面目前未呈現固定翼構型的配置資訊。
   - 參考 TitanPlanner 的 Motor Setup 呈現方式，依連線構型切換清楚、直觀的示意圖與測試項目。
   - 多旋翼：呈現馬達編號、輸出通道、位置與 CW／CCW 旋向。
   - 固定翼：呈現推進馬達及主要舵面／Servo 輸出配置，不套用多旋翼旋向圖。
   - VTOL／QuadPlane：同時區分垂直起降馬達與固定翼推進／舵面輸出。
   - 測試操作需沿用原 Mission Planner／MAVLink 安全限制，並保留移除螺旋槳及上鎖狀態提示。

4. **優化地圖拖曳延遲**
   - 拖曳整張地圖時仍有 LAG。
   - 後續需檢查：限禁航區圖層、路線／圖標重繪、地圖位置事件、LOG、圖磚更新與 UI 執行緒負載。
   - 拖曳期間只執行必要位移；昂貴計算延後至拖曳結束。

5. **修正任務規劃數值欄位顯示**
   - 航點半徑、盤旋半徑、預設高度仍未顯示數值。
   - 預期：首次進入、切換主題、切換語言及重新連線後皆能顯示並可編輯。

6. **高度基準選單繁體中文化**
   - `Relative` 等高度基準選項仍顯示英文。
   - 預期：選單繁體中文化，例如「相對高度」，但保留原始 enum／MAVLink 值，避免影響任務資料。

## 下次版本驗證重點

- 分別連線固定翼、多旋翼及 VTOL／QuadPlane 實機或模擬飛控，驗證地圖圖示及馬達測試頁面的構型資訊。
- 在載入台灣限禁航區及大量航點後測試地圖拖曳流暢度。
- 驗證三個任務數值欄位於首次啟動、重新進入及主題切換後的可見性。
- 驗證高度基準選單只改顯示文字，不改寫任務高度框架值。

## V1.0.9 後新增待修項目（2026-08-15）

7. **版本更新說明繁體中文亂碼**
   - 「FMTPlanner 版本更新」視窗內的 V1.0.9、V1.0.8 更新內容出現亂碼及方框字元。
   - 已確認 `CHANGELOG-FMT.md` 的部分繁體中文內容本身已損壞，後續需修復更新紀錄來源，並統一以 UTF-8（建議 UTF-8 with BOM 或程式明確指定 UTF-8）讀取與顯示。
   - 預期：版本標題、日期、項目符號及所有繁體中文在不同 Windows 語系下皆正常顯示。

8. **版本更新視窗內容遮蔽操作按鈕**
   - 更新說明過長時，內容區會延伸至視窗底部並遮住「是／否」按鈕，右下按鈕也可能被視窗邊界裁切。
   - 預期：說明區可使用滑鼠滾輪及捲軸上下瀏覽；操作按鈕固定在獨立的底部列，不受內容長度、Windows DPI 或字型縮放影響。
   - 視窗需設定合理的最小尺寸，並驗證 100%、125%、150% 顯示縮放。

9. **更新提示按鈕回傳型別錯誤**
   - 按下更新提示按鈕時可能發生 `Microsoft.CSharp.RuntimeBinder.RuntimeBinderException`。
   - 錯誤內容：無法將類型 `int` 隱含轉換為 `System.Windows.Forms.DialogResult`；堆疊指向 `MainV2.cs` 的 `checkFmtUpdate` 回呼（畫面約第 4724 行）。
   - 預期：更新視窗所有回傳路徑統一使用 `DialogResult`；「是」開啟 FMTPlanner 發布頁，「否」正常關閉，不再進入 Send Error 視窗。

## V1.0.9 後更新視窗驗證重點

- 使用含多版長篇繁體中文內容的更新紀錄，確認無亂碼、方框字元或錯誤換行。
- 在 100%、125%、150% Windows 顯示縮放下確認說明區可捲動，且「是／否」按鈕完整可見、可按。
- 分別測試有新版、無新版、網路中斷、按「是」、按「否」與右上角關閉等路徑，確認皆不會出現例外。
- 確認按「是」只會開啟 FMTPlanner 的 GitHub 發布頁，按「否」及關閉視窗不會啟動瀏覽器。
