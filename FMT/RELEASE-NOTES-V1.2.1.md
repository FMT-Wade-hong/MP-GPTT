# FeiMaoTecPlanner V1.2.1

正式發布版，無 RC 後綴。

## 修正

- 修正 V1.2.0 軟體標題仍顯示 V1.1.9 的問題。
- 介面標題、登入畫面、參數視窗、錯誤回報與更新判斷統一使用應用程式 assembly 版本，不再維護另一份寫死的版本字串。
- 新增版本一致性回歸測試，核對實際視窗、EXE、專案與打包版本。
- 保留 V1.2.0 的電源模組入口、繁體中文介面與參數語意校正。

## 驗證

- 38 組離線測試通過，包含 156 個翻譯語意案例、版本匹配、ELRS、模擬通訊、接力控制及圖示等檢查。
- 編譯 0 錯誤、1,450 個警告；套件另檢查必要檔案、私人資料排除與二進位雜湊。
- 未完成實機飛行／群飛驗證；全表中文覆蓋不代表逐條語意複核全部完成。

## 安裝

下載 `FMTPlanner-V1.2.1.zip`，完整解壓縮後執行 `FMTPlanner-V1.2.1.exe`，不要只複製 EXE 或從 ZIP 內啟動。附 SHA-256 校驗檔。升級前請備份設定並先完成地面驗證。

詳見 `FMT/RELEASE-AUDIT-V1.2.1.md` 與 `CHANGELOG-FMT.md`。
